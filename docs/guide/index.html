ライセンスキーのお届け（重要）

本ソフトウェアのライセンスキーは、ご購入後に BOOTH のメッセージ機能を通じてお送りします。これには数時間〜数日かかる場合がございます。メッセージが届かない場合は、BOOTH の注文履歴からご確認いただけます。

Vylite とは

Vylite は、Windows システムの隠れたポテンシャルを最大限に引き出す、次世代パフォーマンス最適化ツールです。

主な機能

Windows の基本的な最適化設定

  • システムの動作を快適にするための各種調整が可能

NVIDIA GPU の詳細設定

  • グラフィックカードの性能を最大限に引き出すカスタマイズ

ネットワーク環境の最適化

  • レイテンシーを低減し、オンライン体験を向上

直感的で使いやすい UI

  • 複雑な調整も簡単に操作できる設計

さらに、推奨設定をワンクリックで適用できる「PC 自動最適化」を搭載。適用時には復元ポイントを自動生成するため、安心して最適化を試せます。

自動最適化はセキュリティ関連の設定を変更しません。VBS や UAC などの項目は、設定ページでユーザーが明示的に切り替えた場合にのみ変更されます。

注意

  • 効果はお使いの PC 環境により異なります

起動方法

1. インストール

Vylite-Setup-x.x.x.exe を実行します。

この時、「Windows によって PC が保護されました」と表示されることがありますが、これはダウンロード実績の少ないソフトウェアに対して Windows SmartScreen が自動的に表示する警告です。ウイルスではありませんのでご安心ください。「詳細情報」→「実行」を選択して通常通りインストールできます。

  • インストールはワンクリックで完了します（管理者権限の確認が表示されます）
  • デスクトップショートカットは自動で作成されます

2. 初回起動

  • 起動時に管理者権限の確認（UAC）が表示されるので「はい」を選択してください（必須）
  • 利用規約に同意し、ライセンス認証画面でキーを入力します（ライセンスキーは BOOTH のメッセージ機能を通じてお送りします）
  • メイン画面に移行します

Was ist Vylite?

Vylite ist ein Leistungsoptimierungstool der nächsten Generation, das das verborgene Potenzial Ihres Windows-Systems voll ausschöpft.

Hauptfunktionen

Grundlegende Windows-Optimierungseinstellungen

  • Vielfältige Anpassungen für ein flüssigeres Systemverhalten

  • Anpassungen, die das Maximum aus Ihrer Grafikkarte herausholen

Optimierung der Netzwerkumgebung

  • Geringere Latenz für ein besseres Online-Erlebnis

Intuitive, einfach bedienbare Oberfläche

  • Auch komplexe Anpassungen lassen sich leicht vornehmen

Außerdem ist die "Automatische PC-Optimierung" enthalten, die empfohlene Einstellungen mit einem Klick anwendet. Beim Anwenden wird automatisch ein Wiederherstellungspunkt erstellt, sodass Sie die Optimierung gefahrlos ausprobieren können.

Die automatische Optimierung ändert keine sicherheitsrelevanten Einstellungen. Elemente wie VBS oder UAC werden nur geändert, wenn Sie sie auf den Einstellungsseiten ausdrücklich umschalten.

Hinweis

1. Installation

Führen Sie Vylite-Setup-x.x.x.exe aus.

Dabei kann die Meldung "Der Computer wurde durch Windows geschützt" erscheinen. Das ist eine Warnung, die Windows SmartScreen bei Software mit wenigen Downloads automatisch anzeigt; es handelt sich nicht um einen Virus. Wählen Sie "Weitere Informationen" und dann "Trotzdem ausführen", um wie gewohnt zu installieren.

  • Die Installation ist mit einem Klick abgeschlossen (es erscheint eine Abfrage der Administratorrechte)

  • Beim Start erscheint die Benutzerkontensteuerung (UAC); wählen Sie "Ja" (erforderlich)
  • Stimmen Sie den Nutzungsbedingungen zu und geben Sie den Schlüssel im Lizenzaktivierungsbildschirm ein (der Schlüssel wird über die Nachrichtenfunktion von BOOTH versendet)
  • Der Hauptbildschirm öffnet sich
