About Vylite

Last updated: September 4, 2026

Your license key (important)

Your license key is sent through BOOTH's message function after purchase. This can take anywhere from a few hours to a few days. If no message arrives, you can check it from your BOOTH order history.

What is Vylite?

Vylite is a next-generation performance optimisation tool that draws out the hidden potential of your Windows system.

Main features

Core Windows optimisation settings

  • A wide range of adjustments that make the system run more smoothly

Detailed NVIDIA GPU settings

  • Customisation that gets the most out of your graphics card

Network optimisation

  • Lower latency for a better online experience

An intuitive, easy-to-use UI

  • Even complex adjustments are simple to operate

Vylite also includes "Automatic PC optimization", which applies the recommended settings with one click. A restore point is created automatically when it is applied, so you can try the optimisation with confidence.

Automatic optimisation never changes security-related settings. Items such as VBS and UAC change only when you switch them explicitly on the settings pages.

Notes

  • Results vary depending on your PC environment

Getting started

1. Installation

Run Vylite-Setup-x.x.x.exe.

Windows may show "Windows protected your PC". This is a warning that Windows SmartScreen shows automatically for software with a small download history; it is not a virus. Choose "More info" and then "Run anyway" to install as usual.

  • Installation completes with one click (you will see an administrator prompt)
  • A desktop shortcut is created automatically

2. First launch

  • When the User Account Control (UAC) prompt appears at launch, choose "Yes" (required)
  • Agree to the Terms of Service and enter your key on the license activation screen (the key is sent through BOOTH's message function)
  • The main screen opens

System requirements

OS

  • Windows 10 / Windows 11

GPU support

  • NVIDIA GPU: supported
  • AMD GPU: not supported

Not supported

  • Laptops (some settings may cause problems)
