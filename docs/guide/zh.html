Vylite 产品说明

最后更新日期：2026年9月4日

许可证密钥的发送（重要）

本软件的许可证密钥将在购买后通过 BOOTH 的消息功能发送给您。这可能需要数小时至数天。如果没有收到消息，可以在 BOOTH 的订单记录中查看。

Vylite 是什么

Vylite 是一款新一代性能优化工具，能够最大限度地发挥 Windows 系统的隐藏潜力。

主要功能

Windows 基础优化设置

  • 可进行多种调整，让系统运行更加流畅

NVIDIA GPU 详细设置

  • 最大限度发挥显卡性能的自定义选项

网络环境优化

  • 降低延迟，提升在线体验

直观易用的界面

  • 即使是复杂的调整也能轻松操作

此外，还内置"PC 自动优化"功能，一键即可应用推荐设置。应用时会自动创建还原点，可以放心尝试优化。

自动优化不会更改与安全相关的设置。VBS、UAC 等项目仅在您于设置页面明确切换时才会更改。

注意

  • 效果因您的电脑环境而异

使用方法

1. 安装

运行 Vylite-Setup-x.x.x.exe。

此时可能会显示"Windows 已保护你的电脑"。这是 Windows SmartScreen 对下载量较少的软件自动显示的警告，并非病毒，请放心。选择"更多信息"→"仍要运行"即可正常安装。

  • 安装一键完成（会显示管理员权限确认）
  • 桌面快捷方式会自动创建

2. 首次启动

  • 启动时会显示用户账户控制（UAC）确认，请选择"是"（必需）
  • 同意使用条款后，在许可证验证界面输入密钥（密钥通过 BOOTH 的消息功能发送）
  • 进入主界面

运行环境

操作系统

  • Windows 10 / Windows 11

GPU 支持情况

  • NVIDIA GPU：支持
  • AMD GPU：不支持

不在支持范围内

  • 笔记本电脑（部分设置可能引发问题）
