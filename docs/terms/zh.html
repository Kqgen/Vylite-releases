Vylite 使用条款

最后更新日期：2026年2月12日

第1条（定义）

本使用条款（以下称"本条款"）规定 Vylite（以下称"本软件"）的使用条件。用户一旦安装或使用本软件，即视为同意本条款。

第2条（使用许可）

  1. 使用本软件需要有效的许可证密钥
  2. 许可证仅授予购买者本人，不得转让、出借或出售
  3. 一个许可证密钥只能绑定一台设备
  4. 许可证的重新验证（迁移到其他电脑）每月仅限一次

2.1 关于许可证的重新验证

重新验证限制：

  • 电脑故障或更换时：每月最多可将许可证迁移到另一台电脑一次
  • 限制期间：过去30天内仅可重新验证一次
  • 重新验证后：原电脑上的许可证将失效
  • 每月第二次重新验证：需等待至下次可用日期

2.2 因硬件变更导致的许可证失效

变更以下硬件后，现有许可证密钥将无法验证，需要重新验证。

需要重新验证的变更：

  • 更换 CPU（处理器）
  • 更换主板（含因故障更换）
  • 更换系统盘（C 盘），包括更换 SSD/HDD 以及克隆
  • 迁移到新电脑
  • 更换显卡（GPU）（部分情况下会受影响）

不受影响的变更：

  • 增加或更换内存（RAM）
  • 增加额外硬盘（D 盘等）
  • 更换电源、机箱、散热风扇
  • 鼠标、键盘、显示器等外设
  • Windows 更新、驱动程序更新

重要：

  • 硬件变更后需要重新验证（每月最多一次）
  • 超过重新验证限制时需等待至下月
  • 购买前如计划升级电脑，请特别注意

2.3 关于验证系统的规格变更

为保证服务稳定运行、防止滥用或进行系统维护，验证服务器的运行规格（包括验证频率、次数和流程）可能在不另行通知的情况下变更。变更可能导致以下情况。

  • 重新验证限制的变更（收紧或放宽）
  • 验证流程的变更
  • 验证所需信息的增加
  • 因安全加强而增加的额外确认

这些变更旨在保护正版用户并防止未经授权的使用。

第5条（隐私政策）

5.1 许可证验证所需信息的发送

为进行许可证验证并防止未经授权的使用，本软件会向验证服务器发送硬件识别信息、应用程序版本和许可证密钥。

服务器会自动记录 IP 地址，用于防止未经授权的访问。

此外，为验证时间，本软件会向外部时间服务器查询（不发送个人信息）。

这些信息仅用于许可证验证和防止未经授权的使用。

5.2 不收集的信息

以下信息不会被收集或发送。

  • 可识别个人身份的信息（姓名、电子邮件地址等）
  • 文件或文档的内容
  • 浏览器浏览历史
  • 键盘输入内容
  • 优化设置的内容或使用情况

5.3 数据保存期限

发送到验证服务器的信息在许可证有效期间以及失效后合理必要的期间内保存。

5.4 数据删除

如希望删除服务器上的数据，请通过商店消息功能联系我们。
