Vylite Nutzungsbedingungen

Zuletzt aktualisiert: 12. Februar 2026

Artikel 1 (Begriffsbestimmungen)

Diese Nutzungsbedingungen (die "Bedingungen") regeln die Nutzung von Vylite (die "Software"). Mit der Installation oder Nutzung der Software erklären Sie sich mit diesen Bedingungen einverstanden.

Artikel 2 (Lizenz)

  1. Für die Nutzung der Software ist ein gültiger Lizenzschlüssel erforderlich
  2. Die Lizenz wird ausschließlich dem Käufer erteilt und darf nicht übertragen, verliehen oder verkauft werden
  3. Ein Lizenzschlüssel kann nur an ein Gerät gebunden werden
  4. Eine erneute Aktivierung (Umzug der Lizenz auf einen anderen PC) ist nur einmal pro Monat möglich

2.1 Erneute Aktivierung

Beschränkungen der erneuten Aktivierung:

  • Bei Defekt oder Austausch des PCs: die Lizenz kann einmal pro Monat auf einen anderen PC übertragen werden
  • Sperrfrist: innerhalb von 30 Tagen ist nur eine erneute Aktivierung möglich
  • Nach der erneuten Aktivierung: die Lizenz wird auf dem bisherigen PC ungültig
  • Zweite erneute Aktivierung im selben Monat: Sie müssen bis zum nächsten möglichen Termin warten

2.2 Ungültigkeit der Lizenz durch Hardwareänderungen

Nach einer der folgenden Hardwareänderungen kann der bestehende Lizenzschlüssel nicht mehr authentifiziert werden, und eine erneute Aktivierung ist erforderlich.

Änderungen, die eine erneute Aktivierung erfordern:

  • Austausch der CPU (des Prozessors)
  • Austausch des Mainboards (auch bei Austausch wegen Defekt)
  • Austausch des Systemlaufwerks (Laufwerk C:), einschließlich SSD/HDD-Wechsel und Klonen
  • Umzug auf einen neuen PC
  • Austausch der Grafikkarte (GPU) (kann sich in manchen Fällen auswirken)

Änderungen ohne Auswirkung:

  • Erweiterung oder Austausch des Arbeitsspeichers (RAM)
  • Hinzufügen weiterer Laufwerke (Laufwerk D: usw.)
  • Austausch von Netzteil, Gehäuse oder Lüftern
  • Peripheriegeräte wie Maus, Tastatur oder Monitor
  • Windows Update und Treiberaktualisierungen

Wichtig:

  • Nach einer Hardwareänderung ist eine erneute Aktivierung erforderlich (einmal pro Monat)
  • Wird das Limit überschritten, müssen Sie bis zum nächsten Monat warten
  • Bitte beachten Sie dies, wenn Sie vor dem Kauf ein PC-Upgrade planen

2.3 Änderungen am Aktivierungssystem

Um den Dienst stabil zu betreiben, Missbrauch zu verhindern oder Wartungsarbeiten durchzuführen, kann das Verhalten des Aktivierungsservers (einschließlich Häufigkeit, Anzahl und Ablauf der Aktivierung) ohne Vorankündigung geändert werden. Dies kann Folgendes zur Folge haben.

  • Änderung der Beschränkungen für die erneute Aktivierung (strenger oder lockerer)
  • Änderung des Aktivierungsablaufs
  • Zusätzliche für die Aktivierung erforderliche Angaben
  • Zusätzliche Prüfungen im Zuge von Sicherheitsverbesserungen

Diese Änderungen dienen dem Schutz rechtmäßiger Nutzer und der Verhinderung unbefugter Nutzung.

Artikel 3 (Wichtige Hinweise zu Systemänderungen)

3.1 Vorherige Einwilligung

Die Software kann die folgenden Vorgänge ausführen.

  • Änderungen an der Windows-Registrierung
  • Änderungen an Systemeinstellungen
  • Änderungen an den Einstellungen des GPU-Treibers
  • Optimierung der Netzwerkeinstellungen
  • Änderungen an den Energieverwaltungseinstellungen

3.2 Verantwortung des Nutzers

  1. Es wird dringend empfohlen, wichtige Daten vorher zu sichern
  2. Es wird empfohlen, einen Systemwiederherstellungspunkt anzulegen
  3. Für die Nutzung der Software sind Administratorrechte erforderlich

Artikel 5 (Datenschutzerklärung)

5.1 Für die Lizenzaktivierung übermittelte Daten

Zur Lizenzaktivierung und zur Verhinderung unbefugter Nutzung übermittelt die Software Hardware-Identifikationsdaten, die Anwendungsversion und den Lizenzschlüssel an den Aktivierungsserver.

Der Server erfasst automatisch die IP-Adresse und verwendet sie zur Abwehr unbefugter Zugriffe.

Zur Zeitprüfung wird außerdem ein externer Zeitserver abgefragt (es werden keine personenbezogenen Daten übermittelt).

Diese Daten werden ausschließlich zur Lizenzaktivierung und zur Verhinderung unbefugter Nutzung verwendet.

5.2 Nicht erhobene Daten

Die folgenden Daten werden weder erhoben noch übermittelt.

  • Personenbezogene Daten (Name, E-Mail-Adresse usw.)
  • Inhalte von Dateien oder Dokumenten
  • Browserverlauf
  • Tastatureingaben
  • Inhalte der Optimierungseinstellungen oder Nutzungsdaten

5.3 Speicherdauer

An den Aktivierungsserver übermittelte Daten werden für die Gültigkeitsdauer der Lizenz und für einen angemessenen Zeitraum nach deren Ungültigwerden gespeichert.

5.4 Löschung von Daten

Wenn Sie die Löschung Ihrer Daten auf dem Server wünschen, kontaktieren Sie uns bitte über die Nachrichtenfunktion des Shops.
